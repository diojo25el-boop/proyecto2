# Los Robles — Comunidad Segura

Prototipo académico en React para mejorar la comunicación vecinal y apoyar la atención rápida de avisos, solicitudes y alertas.

## Sprint 1
Objetivo: entregar una interfaz funcional donde un vecino pueda publicar una comunicación y consultar comunicaciones recientes.

## Funciones
- Publicar aviso, alerta o solicitud.
- Visualizar comunicaciones recientes.
- Identificar alertas activas.
- Simular una alerta de seguridad.
- Cambiar estado de solicitudes.
- Diseño responsive.

## Ejecutar
npm install
npm run dev
